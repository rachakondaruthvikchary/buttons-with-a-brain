# Buttons with a Brain

🚀 **[View the Live Demo!](https://rachakondaruthvikchary.github.io/buttons-with-a-brain/)**

A single AI "Generate" button, wired up with a real lifecycle: it thinks, it succeeds, it sometimes fails — and it never leaves you guessing which state it's in. Every transition uses compositor-friendly transforms and opacity, tuned durations, and easing chosen on purpose, not by default.

## Features

- **State Machine**: `idle -> loading -> success | error -> idle`
- **Motion Design**: Every transition in this component is intentional. Nothing animates just because it can — each duration and easing curve is chosen to match what the state change is communicating.
- **Accessibility**: ARIA live regions and visually distinct states ensure the interface works well for all users, including those who prefer reduced motion.
- **Console Log**: The button's brain, thinking out loud.
- **Single File**: Built with plain HTML, CSS, & JavaScript.

## Setup

Since this is a standalone HTML file, you don't need any complex build steps. Simply open `index.html` in your favorite web browser!

## Demo

Open `index.html` and click the "Generate" button to see the micro-interactions in action. You can also force specific outcomes (success, error, disabled) using the demo controls.
